# 关键 Prompt

本文档记录用户在开发过程中输入的关键 Prompt。

---

## Prompt 1 — 初始需求

```
面向设计师和研发人员的agent，输入校园系统截图，输出适老化/无障碍界面改造方案。
要求：
- 上传截图后自动检测 + 人工辅助标注区域
- 双引擎分析：规则引擎（V层视觉指标）+ AI语义判断（盘古大模型）
- 输出：标注图 + 问题清单 + 改造后效果 + 可交付验收报告
```

**意图**：描述产品目标和核心功能，启动方案设计。

---

## Prompt 2 — 要求优化

```
针对这3个问题给我可执行的优化建议，每个问题给出具体的技术替代方案：
1. 自动区域分割不可验收
2. Puppeteer体积超限/内网不可达
3. 代码diff引入新库违反约束
```

**意图**：要求对可行性评估中发现的 3 个问题给出具体解决方案。

---

## Prompt 3 — 整合 + 修正原则

```
整合成完整步骤，并按以下原则修正：

原则一：每个功能都必须有"我能用肉眼判断对错"的验收标准
原则二：任何失败时不会报错、只会静默出错的功能，一律砍掉

修正意见：
1. 自动分割改为用户手动画框
2. Puppeteer删除
3. 代码diff删除
4. 像素替换需逐像素判断RGB欧氏距离
5. PDF导出需同时提供图片式和打印式
6. AI失败自动降级不阻断
...（共12条）
```

**意图**：确立设计原则，整合为完整流程，给出 12 条具体修正意见。

---

## Prompt 4 — 开始开发

```
开始做吧
```

**意图**：确认方案，启动代码开发。

---

## Prompt 5 — 产品介绍

```
请给我这个产品到目前为止的完整的作品介绍：包含场景背景、功能架构、核心亮点、
码道应用说明以及它的使用教程。整理成PDF的形式
```

**意图**：生成可打印的产品介绍文档。

---

## Prompt 6 — 交付 PPT

```
整理成让我可以编辑的ppt，注意排版要干净整洁，以黑白灰为基底。
先给我整理一版操作这个流程的sop文档，我审核通过后开始完成
```

**意图**：生成交付 PPT，要求黑白灰配色、可编辑。

---

## Prompt 7 — 开源 Skill

```
请在当前项目中创建一个可以开源的 Skill：
- Skill 名称：Elderly-friendly/barrier-free interface modification
- 每张卡片包含：issueId/regionId/category/level/severity/...
- 要求：输入截图+画框标注+双引擎检测
- 暂不支持：自动分割/URL抓取/代码diff/...
```

**意图**：创建可开源的 Skill 文档。

---

## Prompt 8 — 安全检查

```
请检查整个项目是否存在：密码或者token、个人隐私、本地绝对路径、
临时文件、测试垃圾文件、不应该公开的内容。先报告检查结果
```

**意图**：发布前安全审查。

---

## Prompt 9 — GitHub 发布

```
请准备把当前项目发布到GitHub:
仓库名称：Elderly-friendly/barrier-free interface modification
可见性：Public
远程名称：origin
推送分支：main
```

**意图**：发布到 GitHub 开源。

---

## Prompt 10 — 整理提交包

```
请你帮我按照上面的要求依次整理好这个项目，我要准备提交
```

**意图**：按比赛要求整理为 ppt/project/video/codearts_proof/readme 五个目录。
