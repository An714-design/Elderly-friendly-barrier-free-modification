CodeArts 一次性生成了 10 个 JS 模块 + HTML + CSS，共 ~700 行代码，纯前端零依赖。后续修复了 ES Module 加载问题，将所有模块改为全局 `App` 命名空间。

## 代码生成特点

### 1. 零依赖设计

- 不使用任何 npm 包
- 不使用 import/export 语法
- 所有模块通过全局 `App` 对象共享
- CDN 引入 html-to-image 和 jsPDF

### 2. 规则引擎架构

每条规则是一个独立对象，含 `check(metrics, level)` 方法：

```javascript
App.RULES['V1'] = {
  id: 'V1',
  name: '对比度-正文',
  standard: 'WCAG 2.1 SC 1.4.3',
  check: function(metrics, level) {
    var threshold = level === 'AAA' ? 7 : 4.5;
    return {
      pass: metrics.contrast >= threshold,
      actual: metrics.contrast,
      threshold: threshold,
      severity: metrics.contrast < 3 ? '高' : '中',
    };
  },
};
```

### 3. 降级安全设计

- AI 分析：try/catch + 8s 超时 → 返回空数组
- 像素替换：前景背景色距 < 容差 → 降级为色块对比
- 所有失败都有用户可见的错误提示
