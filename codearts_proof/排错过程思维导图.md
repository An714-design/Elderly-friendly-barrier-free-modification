# 排错过程思维导图

## 4 个工程问题的诊断与修复

```
排错过程
│
├─ 问题1：页面无法打开
│  ├─ 现象
│  │  └─ 浏览器空白页，JS 未执行，控制台无报错
│  │
│  ├─ 诊断
│  │  ├─ 检查 index.html 的 <script> 标签
│  │  ├─ 发现 JS 文件使用 import/export 语法
│  │  └─ 确认环境未安装 Node.js
│  │
│  ├─ 原因
│  │  └─ ES Module (import/export) 需要 HTTP 服务器 + 正确 MIME type
│  │     环境无 Node.js，浏览器以 file:// 协议加载时不支持 ES Module
│  │
│  └─ 修复
│     ├─ 将所有 JS 文件从 import/export 改为全局 App 命名空间
│     ├─ 例：export function foo() {} → App.foo = function() {}
│     ├─ 例：import { bar } from './bar.js' → 直接使用 App.bar
│     └─ <script> 标签按依赖顺序加载（app.js → canvas.js → ... → main.js）
│
├─ 问题2：JS 文件加载失败
│  │
│  ├─ 现象
│  │  └─ 控制台报错：Refused to execute script from 'xxx.js'
│  │     because its MIME type ('application/octet-stream') is not executable
│  │
│  ├─ 诊断
│  │  ├─ 检查 Python http.server 的 MIME type 映射
│  │  ├─ 发现 .js 文件未注册 MIME type
│  │  └─ 服务器返回 application/octet-stream，浏览器拒绝执行
│  │
│  ├─ 原因
│  │  └─ Python http.server 的默认 mimetypes 不含 .js → text/javascript
│  │     在 Windows 环境下尤其常见（注册表缺失）
│  │
│  └─ 修复
│     ├─ 创建自定义 server.py
│     ├─ 继承 ThreadingHTTPServer
│     ├─ 覆盖 extensions_map，添加：
│     │  '.js': 'text/javascript'
│     │  '.css': 'text/css'
│     │  '.html': 'text/html'
│     └─ 验证：Invoke-WebRequest 返回正确的 Content-Type
│
├─ 问题3：服务器不稳定
│  │
│  ├─ 现象
│  │  └─ 页面偶尔加载超时，刷新后恢复正常
│  │
│  ├─ 诊断
│  │  ├─ 检查 Python http.server 源码
│  │  └─ 发现 TCPServer 默认单线程，并发请求阻塞
│  │
│  ├─ 原因
│  │  └─ 单线程 TCPServer 一次只能处理一个请求
│  │     浏览器并发加载多个 JS/CSS 文件时，后续请求排队等待
│  │
│  └─ 修复
│     ├─ 改用 ThreadingMixIn 多线程服务器
│     ├─ class Handler(SimpleHTTPRequestHandler): pass
│     ├─ class Server(ThreadingMixIn, HTTPServer): pass
│     └─ 每个请求在独立线程中处理，不再阻塞
│
└─ 问题4：子进程被清理
   │
   ├─ 现象
   │  └─ PowerShell 命令结束后，服务器进程自动退出
   │
   ├─ 诊断
   │  ├─ 检查 Start-Process 的行为
   │  └─ 发现子进程生命周期绑定到父 PowerShell 进程
   │
   ├─ 原因
   │  └─ Start-Process 启动的子进程在父进程结束时被清理
   │     PowerShell 命令执行完毕后，父进程退出，子进程被终止
   │
   └─ 修复
      ├─ 使用 cmd /c start /b python server.py 后台启动
      ├─ 或使用 Start-Process -WindowStyle Hidden
      └─ 服务器进程独立于 PowerShell 命令生命周期
```

## 排错总结

| 问题 | 根因 | 修复方式 | 验证方法 |
|---|---|---|---|
| 页面空白 | ES Module 不支持 | 改为全局 App 命名空间 | 浏览器正常加载执行 |
| JS 加载失败 | MIME type 缺失 | server.py 自定义 MIME | Content-Type 返回 text/javascript |
| 服务器超时 | 单线程阻塞 | ThreadingMixIn 多线程 | 并发请求不阻塞 |
| 进程退出 | 子进程生命周期 | cmd /c start /b 后台启动 | 服务器持续运行 |

**排错原则**：每个问题都定位到根因，而非表面现象。修复后都有验证步骤确认问题解决。
