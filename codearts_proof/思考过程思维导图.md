# 思考过程思维导图

## CodeArts 方案设计推理过程

```
适老化改造 Agent
├─ 可行性评估
│  ├─ ✅ 截图 + Canvas → 视觉检测可行
│  │  └─ 理由：Canvas API 可读取像素，计算对比度/尺寸等客观指标
│  ├─ ⚠️ 自动分割 → 过分割不可验收，砍掉
│  │  └─ 理由：UI截图过分割、汉字连通域碎裂、无法判断对错
│  └─ ❌ Puppeteer → 体积超限/内网不可达/合规风险
│     └─ 理由：Chromium 200MB+、校园内网登录验证码、截图含学生信息
│
├─ 方案设计
│  ├─ 原则一：肉眼可验收
│  │  └─ 每个功能都有"我能用肉眼判断对错"的验收标准
│  │     · 反例：【分割出多少个区域】→ 多少算对？无法判断
│  │     · 正例：【框选区域，算出对比度 3.18:1】→ 能和 3.18 对上就对
│  │
│  ├─ 原则二：禁止静默出错
│  │  └─ 失败不报错的功能一律砍掉
│  │     · 报错能复制修复；算法错了根本不知道自己错了
│  │
│  └─ 12 阶段完整流程
│     ├─ 阶段 0-2：输入（模式选择 → 截图上传 → 画框标注）
│     ├─ 阶段 3-5：检测（V层指标 → 规则引擎 → AI语义）
│     ├─ 阶段 6-7：输出（合并去重 → 标注图+清单）
│     ├─ 阶段 8-9：详情（色块对比/像素替换/尺寸示意 → 整页效果）
│     └─ 阶段 10-11：导出（PNG/PDF → 复检闭环）
│
├─ 技术选型
│  ├─ 纯前端零依赖
│  │  ├─ Canvas API + 原生JS（无框架）
│  │  ├─ 全局 App 命名空间（无 ES Module）
│  │  └─ CDN 引入 html-to-image + jsPDF
│  │
│  ├─ K-means 聚类提取前景/背景色
│  │  └─ 区域内像素采样(step=2) → 聚为4簇 → 按亮度排序 → 最亮=背景/最暗=前景
│  │
│  ├─ 规则引擎 + AI 双引擎
│  │  ├─ V层8条：对比度/字号/尺寸/颜色/行高/间距（截图可判）
│  │  ├─ S层4条：label/alt/ARIA/标题层级（需DOM）
│  │  └─ AI：盘古大模型做语义判断，8s超时降级返回[]
│  │
│  └─ 导出双方案
│     ├─ 图片式：html-to-image → jsPDF.addImage（中文无字体问题）
│     └─ 打印式：window.print + @media print（文字可搜索）
│
├─ 改造详情设计
│  ├─ 色块对比（text/component）
│  │  └─ 左"改造前"色块 + 右"改造后"色块，标注新旧对比度
│  │
│  ├─ 背景像素替换（background，含降级）
│  │  ├─ 前置安全检查：fgBgDist < tolerance(35) → 降级为色块对比
│  │  └─ 逐像素替换：rgbDistance(pixel, bgColor) < tolerance 才替换
│  │
│  └─ 尺寸示意（size）
│     └─ 左"改造前"尺寸 + 右"改造后"尺寸，并排可视化
│
└─ 开发执行
   ├─ 10 个 JS 模块
   │  ├─ app.js（全局状态）→ canvas.js（工具）→ metrics.js（指标）
   │  ├─ rules.js（规则引擎）→ ai.js（AI分析）→ merge.js（合并去重）
   │  └─ render.js（渲染）→ fix.js（改造详情）→ export.js（导出）→ main.js（入口）
   │
   ├─ ES Module → 全局 App 命名空间
   │  └─ 原因：环境无 Node.js，不支持 import/export 语法
   │
   └─ Python 服务器 MIME type 修复
      └─ 原因：http.server 默认不注册 .js MIME，浏览器拒绝加载
```

## 设计决策记录

| 决策点 | 选择 | 理由 |
|---|---|---|
| 区域来源 | 用户手动画框 | 自动分割不可验收（原则一） |
| 检测模式 | A(截图) + B(截图+DOM) | 删除 Puppeteer URL 抓取（原则二） |
| AI 失败处理 | 降级返回空数组 | 不阻断规则引擎结果（原则二） |
| 改造呈现 | 真实位置颜色变化 | 不做整页重绘，只在框选区域内呈现 |
| 像素替换 | 逐像素判断 + 降级 | 前景背景色距<容差时降级为色块对比 |
| PDF 导出 | 双方案 | 图片式(无字体问题) + 打印式(可搜索) |
| 代码组织 | 全局 App 命名空间 | 无 Node.js，不支持 ES Module |
