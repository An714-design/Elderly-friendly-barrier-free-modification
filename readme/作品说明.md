# 作品说明文档

## 适老化无障碍界面改造工具

> 上传截图 · 画框标注 · 双引擎检测 · 一键导出验收报告

---

## 一、环境依赖

### 运行环境

| 依赖 | 版本要求 | 用途 | 必需 |
|---|---|---|---|
| Python | ≥ 3.x | 启动开发服务器 | ✅ 必需 |
| 现代浏览器 | Chrome / Edge / Firefox | 运行应用（需支持 Canvas API） | ✅ 必需 |

### 无需安装

| 依赖 | 说明 |
|---|---|
| Node.js | 不需要 |
| npm / yarn | 不需要 |
| 前端框架（React/Vue/Angular） | 不需要 |
| 构建工具（webpack/vite/rollup） | 不需要 |

> **零依赖设计**：纯静态 HTML/CSS/JS，无需 `npm install`，无需任何构建步骤，克隆后直接运行。

## 二、部署步骤

### 步骤 1：获取项目代码

```bash
git clone https://github.com/An714-design/Elderly-friendly-barrier-free-modification.git
cd Elderly-friendly-barrier-free-modification
```

或直接解压 `project/` 目录中的源码。

### 步骤 2：启动开发服务器

```bash
python server.py
```

服务器启动后显示：
```
Serving on http://localhost:8888
```

### 步骤 3：打开应用

浏览器访问 **http://localhost:8888/index.html**

### 步骤 4：开始使用

1. **配置参数** → 选择模式（A=纯截图 / B=截图+DOM）、标准（AA/AAA）、DPR
2. **上传截图** → 拖拽 / 粘贴 / 选文件
3. **隐私确认** → 勾选"已确认截图中无敏感个人信息"
4. **画框标注** → 在截图上拖拽画框，选择类型（文字/控件/图标/背景）
5. **开始检测** → 点击"开始检测"，规则引擎 + AI 自动分析
6. **查看结果** → 标注图 + 问题清单 + 改造详情
7. **导出报告** → PNG / PDF（图片式）/ PDF（打印式）

### 步骤 5：观看演示（可选）

**在线演示视频（推荐）：** https://an714-design.github.io/Elderly-friendly-barrier-free-modification/

打开即可在线播放，无需下载、无需本地环境（适用于手机、平板、电脑）。

**完整交付材料库：** https://an714-design.github.io/Elderly-friendly-barrier-free-modification/docs/

### 本地自播演示

访问 **http://localhost:8888/demo.html** 观看 8 步自动播放演示（约 22 秒）

### 验证部署成功

打开浏览器后应看到：
- 标题"适老化 / 无障碍界面改造"
- 模式选择下拉框
- 标准档位选择
- "开始"按钮

## 四、码道应用总结

### 4.1 什么是华为云码道 (CodeArts)

华为云码道 (CodeArts) 是华为云推出的代码智能体，能够理解自然语言需求，自动完成从方案设计到代码编写、构建验证的全流程开发工作。

### 4.2 CodeArts 在本项目中的应用流程

| 步骤 | 说明 |
|---|---|
| 💬 需求对话 | 用户描述适老化改造需求，CodeArts 评估可行性，识别 3 个关键问题 |
| 📋 方案设计 | 生成 12 阶段 SOP 文档（593行），经多轮修正定稿 |
| 🏗️ 代码生成 | 10 个 JS 模块 + HTML + CSS，纯前端零依赖，~700 行代码 |
| 🔍 问题修复 | 修复 ES Module 加载、MIME Type、线程阻塞、子进程 4 个工程问题 |
| 🎬 演示制作 | 生成 8 步自动播放演示页面 demo.html |
| 📦 交付整理 | 生成产品介绍文档 + 交付 PPT + 开源 Skill + README |

### 4.3 关键能力体现

| 能力 | 本项目中的体现 |
|---|---|
| 需求理解与方案设计 | 从一句话需求 → 593 行完整 SOP（含 12 阶段/规则库/数据结构/验收标准） |
| 多轮对话修正 | 3 轮大修正：删除自动分割/Puppeteer/diff，确立肉眼可验收+禁止静默出错两大原则 |
| 全栈代码生成 | 10 个 JS 模块共 ~700 行，覆盖 Canvas 绘图/K-means 聚类/规则引擎/AI 调用/报告导出 |
| 工程问题排查 | 自动诊断并修复 MIME type 缺失/ES Module/线程阻塞/子进程 4 个问题 |
| 一体化交付 | 代码 + SOP 文档 + 演示页面 + 产品介绍 + 交付 PPT + 开源 Skill |

### 4.5 技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| 前端核心 | Canvas API + 原生 JavaScript | 零框架依赖，纯静态 HTML/CSS/JS |
| 颜色分析 | K-means 聚类 | 区域内像素聚类提取前景色/背景色 |
| 对比度计算 | WCAG 相对亮度公式 | sRGB 线性化 → L=0.2126R+0.7152G+0.0722B |
| AI 分析 | 盘古视觉大模型（云函数） | try/catch + 8s 超时降级，失败不阻断 |
| 导出 PNG | html-to-image (CDN) | toPng(node, {pixelRatio: 2}) |
| 导出 PDF | jsPDF (CDN) + window.print | 双方案：图片式 + 打印式 |
| 开发服务器 | Python http.server (ThreadingMixIn) | 自定义 MIME type，端口 8888 |
